# زرنگار — نسخه وب و بک‌اند Node.js

این پوشه شامل نسخه کامل **بک‌اند Node.js (REST API + ذخیره‌سازی پایدار)** و **فرانت‌پیج مینیمال فارسی (تم روشن و تاریک)** اپلیکیشن حسابداری طلا و ارز **زرنگار** است.

## اجرای سریع (بدون نیاز به نصب پکیج اضافی)

تنها پیش‌نیاز **Node.js نسخه ۱۸ به بالا** است:

```bash
cd nodejs-fullstack
node server.js
```

سپس در مرورگر آدرس زیر را باز کنید:

```
http://localhost:3000
```

## اجرای تست‌های خودکار بک‌اند

```bash
cd nodejs-fullstack
npm test
```

## امکانات پیاده‌سازی‌شده
- بدون صفحه ورود اجباری و بدون نمودار قیمتی شلوغ
- طراحی مینیمال با **تم روشن و تاریک**
- **تابلو نرخ آنلاین (API) + ورود دستی نرخ طلا و دلار**
- **تفکیک کامل موجودی طلا** (آبشده، شمش ۲۴ عیار، طلای نو ویترینی، کارکرده بدون اجرت، سایر) + موجودی دلار
- **حساب‌های بانکی، کارت شخصی و تنخواه** با نمایش لحظه‌ای **معادل گرمی طلای ۱۸ عیار**
- **تعریف ۳ تا ۵ فروشنده مغازه** با ثبت جزئیات ورود و خروج طلا و دلار
- **پیامگیر صوتی فارسی (Web Speech API + تحلیل کلیدواژه)** با صف آفلاین و ارسال خودکار به گوگل شیت به محض اتصال اینترنت
- **رفع کامل ارور Access Blocked گوگل شیت** از طریق وب‌اپ مستقیم Google Apps Script
- **بخش مخارج مغازه** با محاسبه معادل گرمی طلا و کسر از سود خالص
- **بخش گزارش‌گیری دوره‌ای** (امروز، ۷ روز، ۳۰ روز، کل دوره) با چاپ و خروجی CSV
